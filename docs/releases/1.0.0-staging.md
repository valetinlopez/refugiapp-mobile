# Refugiapp Mobile 1.0.0 — staging

- Estado: candidata; builds EAS pendientes de sesión autorizada y URL real de staging.
- Ticket: RFG-90
- Canal: distribución interna
- Fecha de preparación: 2026-10-01

## Cambios

- Perfil EAS `staging` para APK Android y distribución ad hoc iOS.
- Variante nativa separada `app.refugiapp.mobile.staging` y nombre **Refugiapp (Staging)**.
- Versionado nativo inicial y autoincremento remoto en EAS.
- Export y escaneo reproducible del bundle cliente para detectar patrones de secretos.
- Runbook y checklists de seguridad, publicación, instalación y smoke test.

## Riesgos y condiciones

- La URL pública de staging debe configurarse en el ambiente EAS `preview`; no se versiona un host de ejemplo.
- iOS requiere registrar los dispositivos de prueba antes del build ad hoc.
- Certificate pinning fue revisado y no se adopta en esta candidata; ver ADR-0013.
